# CRM Sônia Lima

Aplicativo privado para operação imobiliária, hospedado no Cloudflare Workers e conectado exclusivamente ao projeto Supabase `oxmtlzvsqwqqdngtzlbm`.

## Desenvolvimento

```sh
npm ci
npm run build:cloudflare
```

Variáveis públicas de exemplo estão em `.env.example`. Integrações externas como Google Apps Script, portais imobiliários e WhatsApp precisam de credenciais próprias da Sônia Lima antes de serem ativadas.

A base nova inicia sem leads, imóveis ou dados comerciais do projeto anterior. A identidade visual usa o logo fornecido pela cliente.
